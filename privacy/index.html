隱私權政策 Privacy Policy

生效日期：2026 年 9 月 28 日

跡行 PathRecall 以「本機優先（local-first）」為設計原則。本政策說明 App 如何處理定位、軌跡、照片、GPX、自訂地圖及網路服務資料。

重點
  • 不要求建立帳號
  • 沒有廣告
  • 不做跨 App／網站追蹤
  • 不出售個人資料
  • 主要資料保存在 iPhone
  • 背景定位只用於主動開始的軌跡記錄

1. 儲存在裝置上的資料

GPS 軌跡、停車位置、樓層／車格／備註、停車照片、遊玩紀錄、匯入的 GPX，以及使用者匯入的自訂圖片或 PDF 地圖，主要儲存在使用者的 iPhone。刪除 App 或相關資料可能使資料永久消失，除非另行匯出或備份。

2. 定位資料

跡行使用 iOS 定位服務顯示目前位置、記錄 GPS 軌跡、保存停車位置、計算附近地點距離及協助路線功能。背景定位只用於使用者主動開始的軌跡記錄。

3. 照片與文字辨識

使用者可拍攝或選取停車照片，保存樓層、區域、車格等線索。照片及辨識結果用於找車功能並保存在裝置上；儲存前請核對辨識結果。

4. 行程影片與照片庫

部分版本提供行程影片分段錄製、事件片段匯出及照片庫儲存。使用者授權後，影片及匯出副本可儲存至 iPhone「照片」App；聲音錄製須由使用者開啟並允許麥克風。刪除 App 內行程關聯資料不必然刪除系統照片庫的原始影片，請於照片庫另外確認與管理。實際功能以安裝版本為準。

5. GPX 與分享

GPX 可由使用者自行匯入或匯出。只有在使用者主動選擇分享或匯出時，相關檔案才會交由 iOS 分享流程傳送至使用者選擇的目的地。

6. 地圖、搜尋與路線服務

使用附近地點、地址或路線查詢時，Apple MapKit 可能接收搜尋位置、起終點或查詢內容，以提供搜尋與路線結果。地圖顯示會向 OpenFreeMap 下載地圖資料，開啟登山地形圖時會向 OpenTopoMap 下載圖磚；連線服務可能取得 IP 位址、請求時間與所請求的地圖區域等必要網路資訊。使用這些服務前請參考相關供應商的隱私政策。App 主要軌跡仍採本機優先保存，並不代表所有地圖及線上查詢均不會傳送位置相關資訊。

7. YouBike 公開資料

在支援地區搜尋 YouBike 2.0 時，跡行會向台南市及高雄市政府公開資料 API 下載即時站點資料，並在裝置上依位置與搜尋半徑篩選。API 服務可能接收必要的網路連線資訊（例如 IP 位址），但目前所檢查的 API 請求不會將裝置 GPS 座標作為查詢參數傳送。即時資料可能延遲、中斷或與現場不同。

8. 使用者匯入地圖

請只匯入自行製作、已取得授權或依法可使用的圖片與 PDF。跡行不會將這些自訂地圖公開提供其他使用者下載。

9. 資料保留與刪除

使用者可透過 App 功能刪除軌跡、停車紀錄或自訂地圖，也可透過 iOS 移除 App 及其本機資料。已主動匯出至其他服務的資料，須依該服務方式管理。

10. 兒童與安全用途

跡行不是社群服務，也不以蒐集兒童個人資料為目的。App 不提供緊急救援、醫療服務或保證可通行的導航。

11. 第三方與政策更新

地圖、開放資料及第三方軟體資訊請參閱授權與來源。若功能或資料處理方式有重大變更，本政策會同步更新。

12. 聯絡

隱私或產品問題請透過官方技術支援頁聯繫。
